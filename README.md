# Divar-Yab 🔍 (دیوار یاب)

یک سرور هوشمند بر پایه **MCP (Model Context Protocol)** برای جستجو، تحلیل و ارزیابی آگهی‌های سایت **دیوار (Divar.ir)** توسط مدل‌های هوش مصنوعی.

با این ابزار، می‌توانید به هوش مصنوعی (مانند Antigravity، کلود، یا هر کلاینت MCP دیگر) بگویید بر اساس نیازهای متنی شما در دیوار جستجو کند، توضیحات آگهی‌ها را بخواند، قیمت‌ها را بسنجد و بهترین گزینه‌ها را به شما پیشنهاد دهد.

---

## 🚀 ابزارهای موجود در MCP Server

| ابزار | توضیحات |
| :--- | :--- |
| `search_divar` | جستجوی تعاملی و چندمرحله‌ای با تشخیص خودکار دسته‌بندی، استخراج دسته‌های مرتبط پیشنهادی دیوار، و اعمال فیلترهای تخصصی هر دسته (سال ساخت، کارکرد، رنگ، متراژ، رهن، اجاره و...). |
| `get_post_details` | دریافت مشخصات کامل یک آگهی، تمام توضیحات فروشنده، ویژگی‌های فنی، تصاویر و وضعیت چت با استفاده از توکن یا آدرس آگهی. |
| `list_cities` | جستجو و دریافت لیست ۱,۱۷۷ شهر پشتیبانی‌شده دیوار همراه با نام فارسی و شناسه. |
| `list_categories` | دریافت لیست دسته‌بندی‌های متداول دیوار (خودرو، املاک مسکونی و تجاری، لپ‌تاپ و...). |

---

### 🎯 پشتیبانی از فیلترهای تخصصی دسته‌ها:

* **خودرو (`light`, `cars`):**
  * `min_year` / `max_year`: سال ساخت شمسی (مثلاً ۱۳۹۸ تا ۱۴۰۲)
  * `max_mileage`: سقف کارکرد به کیلومتر (مثلاً ۸۰,۰۰۰)
  * `color`: رنگ (سفید، مشکی، نقره‌ای، خاکستری...)
  * `gearbox`: گیربکس (دنده‌ای یا اتوماتیک)
* **املاک (`residential-rent`, `residential-sell`):**
  * `min_size` / `max_size`: متراژ به متر مربع
  * `min_credit` / `max_credit`: ودیعه / رهن به تومان
  * `min_rent` / `max_rent`: اجاره ماهیانه به تومان
  * `has_elevator`: آسانسور (true/false)
  * `has_parking`: پارکینگ (true/false)
* **دیجیتال و لپ‌تاپ (`laptops`, `mobile-phones`):**
  * `min_ram`: حداقل رم به گیگابایت (مثلاً ۱۶ یا ۳۲)
  * `min_storage`: حداقل حافظه داخلی (مثلاً ۵۱۲)
  * `cpu`: نوع پردازنده

## 🛠️ ساختار پروژه

```
divar-yab/
├── src/
│   ├── __init__.py
│   ├── divar_client.py    # کلاینت ارتباط مستقیم با API دیوار + فیلترهای هوشمند
│   ├── mcp_server.py      # پیاده‌سازی ابزارهای MCP با MCPServer
│   └── models.py          # ساختارهای داده Pydantic
├── tests/
│   └── test_mcp.py        # آزمون‌های خودکار یکپارچگی و سلامت ابزارها
├── pyproject.toml
├── requirements.txt
└── README.md
```

## 🔌 نحوه اتصال به کلاینت‌های مختلف MCP

### Antigravity
تنظیمات در فایل `~/.gemini/config/mcp_config.json` اعمال شده است:
```json
{
  "mcpServers": {
    "divar": {
      "command": "/home/javad/Projects/ai/divar-yab/.venv/bin/divar-mcp"
    }
  }
}
```
