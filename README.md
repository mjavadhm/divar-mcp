# Divar-Yab 🔍 (دیوار یاب)

یک سرور هوشمند بر پایه **MCP (Model Context Protocol)** برای جستجو، تحلیل و ارزیابی آگهی‌های سایت **دیوار (Divar.ir)** توسط مدل‌های هوش مصنوعی.

با این ابزار، می‌توانید به هوش مصنوعی (مانند Antigravity، کلود، یا هر کلاینت MCP دیگر) بگویید بر اساس نیازهای متنی شما در دیوار جستجو کند، توضیحات آگهی‌ها را بخواند، قیمت‌ها را بسنجد و بهترین گزینه‌ها را به شما پیشنهاد دهد.

---

## 🚀 ابزارهای موجود در MCP Server

| ابزار | توضیحات |
| :--- | :--- |
| `search_divar` | جستجو در آگهی‌ها بر اساس کلیدواژه، شهر، دسته‌بندی و بازه قیمتی (با فیلتر اتوماتیک قیمت به تومان). |
| `get_post_details` | دریافت مشخصات کامل یک آگهی، تمام توضیحات فروشنده، ویژگی‌های فنی، تصاویر و وضعیت چت با استفاده از توکن یا آدرس آگهی. |
| `list_cities` | جستجو و دریافت لیست شهرهای پشتیبانی‌شده دیوار همراه با نام فارسی و شناسه. |
| `list_categories` | دریافت لیست دسته‌بندی‌های متداول دیوار (لپ‌تاپ، خودرو، املاک مسکونی و تجاری، و...). |

```

├── src/
│   ├── __init__.py

└── README.md
```

## ⚙️ راه‌اندازی و نصب

### ۱. پیش‌نیازها
* پایتون نسخه 3.10 یا بالاتر
* ساخت محیط مجازی (Virtualenv):

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
```

### ۲. اجرای تست‌ها
برای اطمینان از سلامت اتصال به دیوار و کارکرد تمام ابزارها:
```bash
.venv/bin/pytest tests/
```

## 🔌 نحوه اتصال به کلاینت‌های مختلف MCP

### ۱. Antigravity
تنظیمات در فایل `~/.gemini/config/mcp_config.json` اعمال شده است:
```json
{
  "mcpServers": {
    "divar": {
      "command": "/home/javad/Projects/ai/divar-yab/.venv/bin/divar-mcp"
    }
  }
}
```

### ۲. Claude Desktop
در فایل تنظیمات کلود (`~/.config/Claude/claude_desktop_config.json` در لینوکس یا `%APPDATA%\Claude\claude_desktop_config.json` در ویندوز):
```json
{
  "mcpServers": {
    "divar": {
      "command": "/home/javad/Projects/ai/divar-yab/.venv/bin/divar-mcp"
    }
  }
}
```
